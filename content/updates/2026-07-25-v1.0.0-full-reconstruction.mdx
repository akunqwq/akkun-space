### 2026-07-25 重大更新（v1.0.0）—— 首页全方位重构

本次为一次架构级大版本：沉浸式首屏、玻璃拟态视觉、三级主题系统、留言板服务端代理全部落地，达成商业级二次元 / 个人博客水准。

**视觉系统 · 全屏沉浸 Hero**
- 全屏 `h-svh` Hero 顶到最上，首屏即沉浸
- `GlobalHero` 路由感知 + 多图层 opacity 互反 Crossfade（真·交叉淡变）
- 箭头 / Tab / Dots 导航 + 悬停暂停 + 可读性 scrim
- `HeroBackground` 背景交叉淡变

**视觉系统 · 玻璃拟态与光感**
- CSS Token 透明化：`--card-bg` / `--card-bg-subtle` / `--card-border` 改为主题感知半透明 rgba
- 全局弥散光晕：layout 3 个 `blur-[120px]` 光球（粉 / 紫 / 天蓝）
- `.glass-glow` 霓虹微边（`color-mix`，全站 20+ 卡片继承）

**布局 · 12 栏毛玻璃重叠**
- 内容层 12 栏毛玻璃面板 `-mt-24 md:-mt-32` 骑在 Hero 底部
- 侧栏 `sticky top-24`
- Header：`fixed top-0` 透明悬浮，滚动后变实底（解决矮 Hero 被切断）

**主题系统 · 三级优先级**
- 默认 Dark，支持系统偏好自动检测（`prefers-color-scheme`）
- 用户手动点击覆盖并 localStorage 持久化
- 优先级：手动 > 系统 > 默认 Dark

**数据层 · 留言板服务端代理**
- 浏览器不再直连 Supabase，改走 Next.js 服务端 `/api/guestbook`
- 根除偶发 `TypeError: Failed to fetch`（跨域 / 客户端网络抖动 / 冷启动）
- 服务端查询带轻量重试；前端保留 3× 指数退避 + 8s `AbortController` 超时

**品牌与设计令牌**
- 品牌强调色定为 **Catkun Pink 🌸**：单一 `--accent` 令牌驱动，全站统一（已扫清散用 `blue-*` / `pink-*`）
- 文本色层级 `--text-primary/secondary/muted`：主信息最亮 > 次要 > 更暗，对齐 Material / Fluent / Apple HIG

**清理**
- 移除废弃壁纸资源站 `someacg` 在 `next.config.ts` 的 `images.remotePatterns`（全仓无残留引用）
