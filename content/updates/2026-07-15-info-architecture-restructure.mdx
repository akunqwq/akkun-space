### 2026-07-15 重大更新（v0.2.0）

本次为一次整体性重构，将原本混杂在 About 页的「关于我 / README / 更新日志」三类内容拆分清晰，并升级了兴趣展示彩蛋。

**信息架构**
- 新增独立的 `/changelog` 页面，承载版本迭代叙事
- About 页只保留固定 / 偶更内容：关于我、博客介绍、技术栈、正在探索、Roadmap
- 技术栈抽离为 `lib/techStack.ts`，单一数据源
- 删除已过时的 `content/updates/2025-12-30-learning-summary.mdx`（内容并入 About 静态区块）

**彩蛋 · 兴趣云（TagWall 升级）**
- 定位降级为纯装饰彩蛋，不再承担信息展示
- 信息展示改用 `ChipList`（可扫读 chip）
- 配色改为 HSL 色环，每个标签独立不重复
- 布局改用 Poisson 磁盘采样 + 长度感知半径 + 安全区，零重叠、不依赖容器宽度
- 每次加载随机洗牌位移（seed 按会话固定，resize 不再重排）
- 桌面 / 移动端通用展示

**清理**
- 移除 About 页左下角 Live2D 占位（规划已并入 Roadmap）
- 删除 `app/components/Live2DWidget.tsx`（已无引用）
