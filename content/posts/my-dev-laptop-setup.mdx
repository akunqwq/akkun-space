# 从轻薄本到生产力工具：我的 i5-1340P 改造记录

## 前言

高考结束后，我购买了人生中的第一台主力笔记本——惠普战66 2023款，搭载 Intel Core i5-1340P 处理器。

在即将进入大学生活前，我对于电脑硬件的理解还只停留在性能参数方面，当时仅关注 CPU 型号、内存容量、显卡性能这些配置，却没有真正理解不同设备定位背后的取舍。

由于预算有限，我最终选择了一台偏商务定位的轻薄本，而不是性能更强但价格更高、重量更大的游戏本。

现在回头来看，这个选择并不完美，但也并不是一个错误。

随着学习计算机开发、接触越来越多的软件工具，这台电脑逐渐从一台普通的学生笔记本，变成了我日常学习和开发中的主力设备。

这篇文章记录的，就是这台 i5-1340P 轻薄本如何通过升级和调整，逐渐适应我的使用需求。

---

# 一、当初为什么选择轻薄本？

刚结束高考时，我对于电脑的理解更多来自硬件参数。


当时觉得：

<Underline>CPU 越强越好；内存越大越好；有独立显卡才算性能强。</Underline>

但真正开始使用电脑后，我才逐渐发现，一台设备是否适合自己，并不只是看配置表。

不同类型的电脑，本身就是针对不同需求设计的：

游戏本更强调性能释放；

轻薄本更注重便携性、续航和日常体验。

对于需要经常携带电脑学习的学生来说，轻薄设备反而更加符合实际需求。

最终，我选择了惠普战66 2023款：

* Intel Core i5-1340P
* Intel Iris Xe 集成显卡
* 轻薄商务设计

它并不是一台为大型游戏打造的设备，但对于我的实际需求来说，它依然能够覆盖大部分日常场景。

除了学习和开发之外，我平时也会使用它进行娱乐，例如游玩《原神》《明日方舟》等游戏。

虽然集成显卡无法和高性能独立显卡相比，但在调整画质和设置后，依然能够满足休闲游戏需求。

这也让我意识到，一台电脑并不一定需要在某一个领域做到极致。

对于学生来说，更重要的是它能否覆盖自己的主要需求：

学习时，它是一台开发工具；

休息时，它是一台娱乐设备；

连接显示器后，它又可以变成一个桌面工作空间。

随着学习深入，这台电脑逐渐承担起浏览资料、编写代码、运行项目等更多任务。

而轻薄本最大的优势——便携性，也让我可以随时携带它进行学习和开发。

---

# 二、为什么升级到 32GB 内存？

最开始购买这台电脑时，16GB 内存已经能够满足大部分日常需求。

这台机器原本搭载：

* 8GB × 2 DDR4 3200MHz
* 16GB 双通道内存

对于浏览网页、观看视频、完成课程作业，甚至进行一些简单开发任务来说，这样的配置已经足够。

但随着学习计算机开发，电脑承担的任务越来越复杂。

从单纯“使用电脑”，逐渐变成“依赖电脑完成学习和开发工作”。

## 从“使用电脑”到“依赖电脑”

在进入到大学专科计算机应用技术专业学习后，我开始到接触更多开发工具：

* VS Code
* Node.js
* Python 环境
* 数据库软件
* 浏览器大量标签页
* 本地开发服务器
* 部署AI

以前写代码，更多的是打开编辑器、查找资料、不断调试。

而现在，AI 工具逐渐成为开发流程的一部分，可以帮助分析代码、寻找问题、优化实现方案。

这意味着电脑需要同时处理更多任务。

例如：

打开 IDE 编写代码；

浏览器查看官方文档；

运行 Node.js 或 Python 服务；

启动数据库；

再搭配AI助手进行辅助开发。

这些程序同时运行时，原本的 16GB 双通道内存并不是不能使用，而是在开发、多任务环境下逐渐接近容量上限。

因此，我选择升级到 32GB。

这次升级的意义并不是提升跑分，而是减少日常使用中的限制，让工作流程更加稳定。

---

# 三、升级后的实际体验

升级到 32GB 后，最大的感受不是“电脑突然变快”，而是使用过程中更加从容。

以前：

打开多个开发工具和浏览器标签后，需要关注内存占用。

现在：

可以更加放心地同时运行多个环境。

对于开发学习来说，这种提升更加明显。

电脑不再需要频繁关闭软件释放资源，而是能够保持当前工作状态。

这台电脑事实上依旧不是高性能工作站，也不是游戏本。

但通过针对性的升级，它已经成为了一台更加适合我的生产力工具。

---

# 四、这台轻薄本仍然存在的局限性：

升级带来的体验提升是真实的，但它并没有改变这台电脑本身的定位。

## 持续高负载性能有限

i5-1340P 日常开发性能足够，但受到轻薄本散热和功耗限制，长时间高负载时仍会出现性能瓶颈。

例如：

* 大型项目编译
* 多个 Docker 容器同时运行
* 虚拟机环境

这些场景下，CPU 持续性能会成为限制因素。

---

## 图形性能存在限制

Iris Xe 集成显卡可以满足日常显示、轻度游戏以及简单图形任务。

例如《原神》《明日方舟》等游戏，在调整画质后依然可以运行。

但面对以下场景时，独立显卡设备会更有优势：

* 大型 3A 游戏
* 复杂视频渲染
* 本地大模型推理
* CUDA 开发等 GPU 加速任务

---

## 内存和平台限制

32GB 内存已经能够满足目前的开发和学习需求。

但它并不是无限的。

同时运行多个微服务、数据库、前端工程以及 AI 工具时，依然可能接近容量上限。

同时，这台电脑采用 DDR4-3200 内存平台，对比更新的平台上内存带宽方面依然存在差距。

不过在实际使用中，内存容量的提升大于内存规格差异的实际体验。

---

## 轻薄设计带来的散热限制

轻薄本最大的优势是便携，但机身空间有限也是事实。

长时间高负载运行时：

* 风扇噪音会上升；
* 机身温度会增加。

这是大部分轻薄本设备厂商为了重量和便携性做出的取舍。

所以这台电脑更像是一台“够用且顺手”的开发机，而不是“全能”工作站。

升级延长了它的服役周期，却没有消除它原本的定位边界。

---

# 最后总结

回顾这台 i5-1340P 轻薄本的使用经历，我觉得设备的价值并不完全取决于定位。

轻薄本不一定只能用于办公；

集成显卡也不代表无法完成开发任务。

真正重要的是，根据自己的需求调整设备，让它服务于自己的工作和学习。

从最初的一台普通学生笔记本，到现在每天使用的开发主力机，这台电脑陪伴我完成了很多学习和折腾。

而升级到 32GB 内存，也算是给它增加了一些继续服役的可能。

未来几年，它依然会继续承担我的开发、学习以及各种折腾任务。
