### 更轻、更快、更好看了

这次主要做了一次「大扫除」——砍掉冗余代码，优化交互细节，让整个站点跑起来更轻盈。

**砍掉累赘**
- 移除 MediaPlayer 播放器系统（15 个组件），页面加载更快
- 清理 MyCard、changelog 页面等废弃模块
- 删除未使用的依赖和配置项

**交互细节升级**
- 主题切换按钮增加滚动智能隐藏，阅读时不挡视线
- TagWall 兴趣标签视觉优化，交互更友好
- Header 导航栏优化

**性能与稳定性**
- 文章列表页重构，元数据读取效率提升
- 全局样式统一调校，深色/浅色模式切换更顺滑
- 留言板接口加固，数据提交更可靠

**其他**
- README 中英文版同步更新
- 文章内容与分类信息修正
