## 1. 七大口径维度定义

### 维度 1：营业收入

| 项 | 定义 |
|---|---|
| 口径 | 指公司财报披露的**合并报表营业收入**（A股）/ **净收入/收益**（港股美股，按公司公告口径） |
| 说明 | A 股公司用"营业总收入"；港股/美股公司用公告中的"收入/收益/净收入"（已扣除渠道分成等）。两者均为合并报表口径，不含少数股东权益部分。 |
| 注意 | 哔哩哔哩用"净营业额总额"（US GAAP，净额法），与其他公司口径有差异，已在数据中标注。 |

### 维度 2：游戏业务收入

| 项 | 定义 |
|---|---|
| 口径 | 指公司财报中**"游戏"相关分部/业务的收入** |
| 界定方式 | 按各公司财报披露的分部划分取数，不自行拆分。具体口径因公司而异，见下表。 |
| 注意 | 网易用"游戏及相关增值服务净收入"（含少量非游戏 VAS，在线游戏占该分部约 97.6%）；哔哩哔哩用"移动游戏"收入（发行/联运收入，非玩家消费流水）；心动用"游戏分部"收入。 |

**各公司游戏业务收入口径一览：**

| 公司 | 游戏收入口径 | 财报原文措辞 |
|---|---|---|
| 腾讯控股 | 国内游戏 + 海外游戏 | "本土市场游戏收入" + "国际市场游戏收入" |
| 网易 | 游戏及相关增值服务 | "游戏及相关增值服务净收入"（在线游戏占~97.6%） |
| 三七互娱 | 网络游戏行业收入 | "网络游戏行业收入"（移动游戏+网页游戏） |
| 世纪华通 | 互联网游戏业务收入 | "互联网游戏业务实现收入"（移动端+电脑端+网页端） |
| 完美世界 | 游戏业务收入 | "游戏业务实现营收"（PC端+移动端+主机） |
| 吉比特 | 主营业务收入（~99.8%为游戏） | "主营业务收入"（境内+境外游戏） |
| 巨人网络 | 游戏相关业务收入 | "游戏相关业务实现收入"（移动端+电脑端） |
| 心动公司 | 游戏分部收入 | "游戏分部"收入（网络游戏+付费游戏） |
| 哔哩哔哩 | 移动游戏收入 | "移动游戏"收入（发行/联运，非玩家流水） |
| 中手游 | 游戏发行 + 游戏开发 | "游戏发行收入" + "游戏开发收入"（不含IP授权） |
| 祖龙娱乐 | 综合游戏发行及运营 + 开发与授权 | "综合游戏发行及运营" + "开发与授权"（纯游戏公司） |
| IGG | 游戏业务收入（手机游戏） | "来自于手机游戏的收入"（不含APP业务） |

### 维度 3：公司总营收

| 项 | 定义 |
|---|---|
| 口径 | 指公司财报**合并报表总营业收入**（含所有业务分部） |
| 说明 | 即维度 1 的营业收入。用于计算"游戏业务占总营收比例"（ratio 字段）。 |

### 维度 4：同比增长

| 项 | 定义 |
|---|---|
| 口径 | yoy_growth = 游戏业务收入的同比增长率 |
| 基准 | 去年同期（即 2025 年 1-6 月）的游戏业务收入 |
| 说明 | 百分比按原始报告币种计算（避免汇率波动干扰）。IGG 按 HKD 计算增长率，其余按 RMB/USD 计算。 |
| 注意 | 中手游的 yoy 为发行+开发合并推算值（-54.5%），非财报直接披露的单行数字。 |

### 维度 5：财年 vs 自然年

| 项 | 定义 |
|---|---|
| 结论 | **12 家公司均使用自然年（1 月-12 月）作为财报报告期**，26H1 = 2026 年 1-6 月，口径一致。 |
| 说明 | 网易财报中文标注为"2026 财年"，但其财年起止 = 自然年（1.1-12.31），与其他公司无异。IGG 财年亦 = 自然年。 |
| 统一换算 | 所有公司数据统一对齐到 26H1（2026 上半年），无需跨财年换算。 |

### 维度 6：币种

| 项 | 定义 |
|---|---|
| 原始币种 | 腾讯/网易/三七/世纪华通/完美/吉比特/巨人/心动/哔哩哔哩/中手游/祖龙：人民币（RMB）；IGG：港币（HKD） |
| 统一换算币种 | 人民币（RMB），单位：亿元 |
| 汇率 | 1 HKD = 0.870 RMB（基于 2026-06-30 美联储公布的 1 USD = 6.7851 RMB，及 HKD 联系汇率 7.80 HKD/USD 推算：6.7851/7.80 = 0.870） |
| 网易 | 原始披露为 RMB（同时提供 USD 换算值），CSV 使用 RMB 原始值，不经过 USD 中转。 |
| IGG | 原始 HKD，CSV 中已按 0.870 汇率换算为 RMB。yoy_growth 按 HKD 原值计算。 |

### 维度 7：单位

| 项 | 定义 |
|---|---|
| 统一单位 | 亿元（人民币），保留 2 位小数 |
| 说明 | A 股公司原始财报单位为"元"，已换算为亿元（÷ 1 亿）。港股公司原始单位为"千元/百万元"，已换算为亿元。 |

## 3. 已知口径差异与注意事项

| # | 差异点 | 影响 | 处理方式 |
|---|---|---|---|
| 1 | 哔哩哔哩"移动游戏"是发行/联运收入（净额法），非玩家消费流水 | B站游戏收入远小于实际平台游戏流水 | CSV 中标注，详情页需注明"为发行/联运收入" |
| 2 | 网易"游戏及相关增值服务"含少量非游戏 VAS | 游戏收入略偏高（在线游戏占97.6%） | 按公司分部口径取数，详情页注明 |
| 3 | IGG 报告币种为 HKD，已按 0.870 换算 RMB | 汇率波动可能导致 RMB 数据与实际有偏差 | 标注原始 HKD 值和汇率，yoy 按 HKD 计算 |
| 4 | 中手游 game_revenue = 发行+开发，不含 IP 授权 | IP 授权（0.23亿）未计入游戏收入 | 按严格口径排除，详情页可单独展示 |
| 5 | 腾讯 total_revenue 为 Q1+Q2 推算（4012.43亿） | 非财报直接披露的 H1 总计行 | 标注为推算值，ratio 相应为推算 |
| 6 | A 股公司用中国会计准则，港股/美股公司用 IFRS/US GAAP | 收入确认时点和口径可能有差异 | 已按各公司公告口径取数，不做准则调整 |
| 7 | 部分公司（巨人/心动/中手游/祖龙/IGG）无 Q1/Q2 分拆 | quarterly.csv 这些公司季度数据为空 | 留空，不编造 |

## 5. 维护建议

1. **第一版人工校验**：本数据集为人工从财报公告和研报整理，阿鲲审核后再导入 Supabase。
2. **季度更新**：财报每季度发布后更新，建议在财报发布后 3-5 个工作日内更新。
3. **25Q3/25Q4 补充**：需查 2025 年报/Q3 单季报补充，建议作为 P1 任务。
4. **汇率更新**：IGG 数据每次更新时按最新财报截止日汇率重新换算。
5. **口径变更**：如某公司财报调整分部划分，需同步更新本规范文档和 CSV。
6. **自动化前提**：口径稳定后可考虑半自动抓取，但必须先以本规范为校验基准。
